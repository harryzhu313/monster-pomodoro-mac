# v4 — macOS 27 菜单栏兼容修复

## 问题与依据

升级 macOS 27 后，左键点击番茄图标会出现「统计与设置 / 退出」菜单，主面板无法展开。修复前已安装应用与仓库使用 Tauri 2.11.5 / tray-icon 0.24.1，与 [Tauri #16035](https://github.com/tauri-apps/tauri/issues/16035) 的复现条件一致。

上游 tray-icon 0.25.1 修复了托盘菜单吞掉左键事件的问题（[#365](https://github.com/tauri-apps/tray-icon/pull/365)），Tauri 2.12.0 已引入该修复。本迭代采用已发布的 Tauri 2.12.4 稳定版本。

## 范围与成功标准

- 定向升级 Tauri 2.12 系列及必要关联依赖，锁定实际验证的版本。
- 左键展开/收起主面板，右键显示原生菜单，正常失焦收起。
- 休息自动弹出并钉住，休息期间不能用托盘点击或失焦免费跳过；自然结束后进入下一轮。
- Rust / 前端既有自动化回归通过，隔离开发版完成真实系统验证。
- 正式应用、真实数据与 Notion 配置在开发验证期间保持隔离；用户验收后才进入正式替换阶段。

## 已确认决策

- 2026-10-21 用户确认：先升级并在隔离开发版验证，验收通过后再替换正式应用。
- 沿用现有 UI、计时状态机、数据 schema、Notion 字段与产品红线；本迭代只修复系统兼容性。
- Computer use 另按 AGENTS 的启动前确认规则取得授权；用户也可手动完成界面验证。

## 交付

2026-10-21 已完成：隔离开发版经用户验收后，备份数据并替换正式应用；用户最终确认正式版左键面板和原数据正常。实施与验收证据见 [.plan/plan.md](.plan/plan.md)。
